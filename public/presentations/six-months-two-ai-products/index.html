04

产品一：让海关数据成为 Agent 的 Context

customs-data-context.md
13 个市场       →  字段和数据质量并不统一
进口商分类       →  判断规模、品类与活跃度
供应链关系       →  国家、供应商与变化轨迹
Agent Context    →  不只给人看，也直接给 AI 使用

# 目标不是多做一份报告，而是把数据变成下一步行动的依据
05

真正难的，是让数据可信

1
Normalize

统一不同国家的数据

字段不一致、质量参差不齐，不能把 13 个市场当成同一张表处理。

2
Verify

压住幻觉和漂移

数据分析不能自相矛盾，更不能生成看起来合理、实际错误的结论。

3
Automate

把整条链路自动化

下载、处理、生成和发布都尽量不依赖人工；这也给项目增加了难度。

4
Recover

找到可恢复的生产流程

我曾经因为准确性问题停了接近一个月，直到重新找到解决路径。

06

产品二：
AI 虚拟外贸业务员

AI 已经足够聪明，业务里不好用，很多时候不是模型不够强，而是它没有拿到足够完整的 Context。

客户是谁、我们卖什么、之前发生过什么、现在出现了什么信号——这些信息要在同一个脑子里。

07

让 Agent 进入一个真实的销售循环

1
CONTEXT

理解

网站、海关数据、公司知识、历史沟通和客户行为。

2
DECIDE

决定

判断下一步动作，必要时推翻旧计划并重新制定方案。

3
ACT + SIGNAL

行动与反馈

邮件、短信、WhatsApp 是目标能力；打开、点击、回复成为新信号。

08

已经跑通的，和接下来要验证的

NOW
  • 客户背景调查与多源 Context 汇总
  • 开发方案和下一步动作的 Agent 决策
  • Demo 主流程能够完整演示
TO VALIDATE
  • 放进真实外贸流程后的稳定性和效果
  • 自动打电话、社媒监测等扩展能力
  • 自动生成目录、页面或视频的实际价值
09

production-reality.md
