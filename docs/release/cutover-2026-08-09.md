## Rollback

Use Cloudflare Workers version rollback for an immediate runtime rollback. For
a source rollback, revert the release commit with a new Git commit, rebuild with
the production `SITE_URL`, and deploy through the Production workflow. Never
rewrite `main` history or delete the R2 cache bucket during rollback.
