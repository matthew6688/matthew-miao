我一直很喜欢折腾软件。

不是为了追每一个新工具，而是想知道：一件原本需要人反复操作的事情，能不能被重新组织，最后变成一个可靠、可以一直运行的系统。

过去，这种想法经常停在原型。开发、维护和整合的成本太高，一个人很难把所有环节都做完整。AI Agent 改变了这条边界。它没有让判断和维护消失，却明显放大了一个人把想法变成软件的能力。

## 我正在探索什么

我目前在 [UChat](https://uchat.au) 担任首席营销官，也在构建 [FengTalk.ai](https://fengtalk.ai)。这些工作虽然形态不同，但都围绕几个相互连接的问题：

- Web coding 如何让想法更快变成真正可用的产品
- AI Agent 如何理解目标，并在边界内持续完成工作
- outreach 如何从零散动作变成可以观察和改进的流程
- company knowledge 如何被整理成团队和 Agent 都能使用的上下文
- 自动化如何接管重复劳动，同时把关键判断留给人

我关心的不只是“能不能跑起来”。一个系统是否可靠、信息是否清楚、失败时能否恢复，以及它是否真的适合业务，往往比第一次演示更重要。

## 为什么写下来

很多 AI 内容停留在产品发布、功能罗列和短暂的新鲜感。我更想记录实际构建过程中发生的事情：做过哪些选择，哪些方案失败了，怎样验证，以及最后为什么保留现在这个版本。

这个网站会主要围绕 Web coding、AI Agent、自动化、outreach、外贸业务和企业知识展开。有时是一篇完整教程，有时是一次产品复盘，也可能只是一个值得继续验证的小发现。

## 从这里开始

第一版网站本身就是一次公开实践：保留一套成熟个人网站的完整设计与交互，同时重建身份、内容、部署和后续维护流程，并让 AI Agent 能够安全地帮助更新博客。

我希望这里最终不只是文章的集合，而是一份长期积累的工作记录。哪些东西真的有用，时间会给出答案。
